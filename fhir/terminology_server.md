# FHIR Terminology Servers

A **FHIR terminology server** provides fast, standards-based access to clinical terminologies like SNOMED CT and AMT. 

Several types of FHIR terminology server are available, including: 
* [Ontoserver](./ontoserver.md) by the CSIRO
* SNOWSTORM by SNOMED International
* HAPI by Smile Digital Health

[A small, independent review of these servers](https://en.rath.asia/blog/2025/04/27/comparing-3-fhir-terminology-services/) was posted in April 2025 by a Thailand-based clinical informatician.

Although the term 'FHIR' appears throughout this space do note that a FHIR **terminology** server acts as a host for the clinical terminology or codes + terms.

This is where a list of standardised, consistent, centrally managed content to be used in separate record systems is held. 

See FHIR **records** server which covers the role of the FHIR Standard in creating standardised clinical care **records** (e.g., events like medication ordering, lab results, or encounter information).
